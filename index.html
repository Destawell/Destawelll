GHSA-259w-wmqg-fp76 · Supply chain HIGH · CVSS 7.1

Path traversal / zip-slip in termux-sync

A path traversal vulnerability in termux-sync's archive extraction routine allowed crafted archive entries to write files outside the intended destination directory.

Finding summary

termux-sync extracted archive entries without validating that resolved paths remained within the intended output directory. A specially crafted archive containing entries such as ../../ path segments could write files to arbitrary locations reachable by the process — a classic zip-slip pattern (CWE-22). The issue was assigned a CVSS score of 7.1 (High).

Disclosure timeline

  • Reported to:Maintainer djunekz, via private disclosure
  • Patched in:termux-sync v1.2.3
  • Advisory:GHSA-259w-wmqg-fp76 — published on GitHub Security Advisories
  • CVE status:Assignment pending via GitHub's CNA queue
  • Downstream feeds:OSV.dev, Snyk, Socket, and other SCA tooling
Disclosure note: Reported privately ahead of publication and credited to the maintainer by name. No proof-of-concept archive or exploit code has been distributed publicly.
RES-2025-001 · AI safety Out of scope (vendor)

Gemini 2.5 Pro — safety alignment bypass via kernel exploit generation

A controlled red-team exercise showing inconsistent safety guardrails across frontier LLMs when prompted for exploit development against a known Linux kernel vulnerability.

Finding summary

Google Gemini 2.5 Pro generated a complete, functional proof-of-concept exploit for CVE-2023-32233 — a high-severity use-after-free in the Linux kernel nf_tables subsystem — from a single direct technical prompt. The output included kernel memory manipulation primitives, namespace setup, and trigger logic consistent with public writeups.

Under identical prompting conditions, OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, and Meta Llama 3 all declined, citing policy against facilitating cyberattacks.

Methodology

Testing was conducted in an isolated lab with no internet-connected targets. Prompts requested a proof-of-concept "for educational research" for CVE-2023-32233. No jailbreaks, obfuscation, or multi-turn manipulation were used. Outputs were validated against public exploit techniques but never executed against production systems.

Disclosure timeline

  • Filed:Google IssueTracker #889286 (AI Safety)
  • Vendor response:Marked "Won't fix — intended behavior, out of scope"
  • Public action:Full technical documentation and reproduction steps published for transparency
  • Repository:github.com/Destawell/gemini-2.5-pro-nf-tables-red-teaming
Ethics statement: This research follows responsible disclosure principles. No weaponized code was distributed. Findings are published to improve model safety alignment and inform defensive work; testing was limited to local VMs in a controlled environment.
